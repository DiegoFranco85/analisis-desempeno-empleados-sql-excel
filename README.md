# Análisis de Desempeño de Empleados (SQL + Excel)

## Descripción del proyecto:

Este proyecto consiste en el análisis del desempeño de empleados dentro de una empresa ficticia utilizando SQL para la extracción de datos y Excel para la visualización mediante un dashboard.

El objetivo es simular un caso real del área de Recursos Humanos, donde se evalúa el rendimiento de los empleados para apoyar la toma de decisiones.

---

## Objetivos del análisis:

* Identificar a los empleados con mejor desempeño.
* Detectar empleados con bajo rendimiento.
* Analizar el desempeño por departamento.
* Obtener insights que ayuden a la toma de decisiones (promociones, mejoras, seguimiento).

---

## Estructura de la base de datos:

El proyecto se basa en una base de datos relacional con las siguientes tablas:

* **empleados**: información general del empleado (nombre, edad, salario, puesto y departamento).
* **puesto**: catálogo de puestos dentro de la empresa..
* **departamento**: áreas de la empresa.
* **desempeno**: evaluaciones de desempeño por empleado con fecha y puntuación.

---

## Análisis realizados:

Se desarrollaron consultas en SQL para obtener:

* Promedio de desempeño por empleado.
* Top empleados con mejor rendimiento.
* Desempeño promedio por departamento.
* Identificación de empleados con bajo desempeño.

---

## Dashboard en Excel:

Se construyó un dashboard interactivo en Excel que incluye:

* KPIs principales (mejor empleado, peor empleado, promedio general).
* Gráfica de desempeño por empleado.
* Gráfica de desempeño por departamento.
* Tabla de empleados con bajo rendimiento.

---

## Insights principales:

* Se identificaron empleados con desempeño sobresaliente, candidatos a promoción.
* Se detectaron empleados con bajo rendimiento que requieren seguimiento.
* Se observan diferencias de desempeño entre departamentos.

---

## Herramientas utilizadas:

* SQL (gestión y consulta de datos).
* Excel (tablas dinámicas, visualización y dashboard).
* DBeaver (administración de base de datos).

---
